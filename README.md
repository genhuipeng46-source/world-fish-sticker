# world-fish-sticker: Global Fish Sticker Library & Open Dataset

**English** · [简体中文](README.zh-Hans.md)

> **Status: `0.1.0-skeleton` (M1 Data Skeleton complete)**
> The open-licensed dataset for **38,184 accepted extant fish species** (93 orders), the **4,221-species v1.0 launch queue**, and the 23-species quality pilot are complete. Next: M2 batch production pipeline and M3 v1.0 sticker generation.

An open-licensed global fish sticker library and structured dataset aligned with **Catalogue of Life (2026-11-11, CC BY 4.0)** and **Wikidata (CC0)**, inspired by [alchaincyf/huashu-bird-sticker](https://github.com/alchaincyf/huashu-bird-sticker).

**AI-generated notice:** All stickers are AI-generated illustrations, **not photographs and not expert-verified taxonomic plates**. Every WebP file embeds XMP metadata (`trainedAlgorithmicMedia`), attribution, and repository link. Do not upload stickers as observations to citizen-science platforms such as iNaturalist, and do not rely on them for scientific identification.
