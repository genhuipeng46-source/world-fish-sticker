### v1.0 相对 v0.2 的主要修订（全部来自 M0.5 试画实测）
1. **增加选图环节（F-71）**：iNat 高赞图常为正面/远景/手抓照，改为“拉 10 张候选拼接触表 → 视觉模型选 1–3 张清晰侧身图”。
2. **修正特殊体形视角规范（F-04）**：背腹扁平底栖鱼（鮟鱇、蝙蝠鱼、扁鲨、鳐/魟）统一 `dorsal` 俯视；双髻鲨禁用混合角度，统一纯 `dorsal` 或纯 `lateral`；圆盘/高身鱼在 3:2 画布上明确左右大留白，防止拉长变形。
3. **收紧审核员边界（F-12）**：`structural_checks` 严格只检查特征卡预设的硬检查清单，禁止审核员自造主观项误杀合格图。
4. **明确抠图技术（F-75）**：浅色/半透明鱼鳍容易被纯色泛洪啃边，后处理必须使用神经网络抠图（`BiRefNet` / `rembg`）；XMP 元数据实测用 Pillow 直接写入，无需 `exiftool`。
5. **精算体积与成本**：实测 1000px 白边 WebP 平均 **45.9 KB**（全量 38,184 种约 **1.67 GB**）；实测平均 **1.96 轮/种**，v1.0（3,500 种）使用 Batch API 预计 **\$150–250**。
6. **生产运行方式**：正式生产必须走付费 Batch API，不能依赖交互式订阅配额。

## 1. 背景

鸟类贴纸库 huashu-bird-sticker 用 AI 给 11,011 种鸟各画了一张统一风格的贴纸，配上结构化数据开源，被网站、App、输入法、科普视频广泛使用。

鱼类目前没有同类资源：现有图片风格不统一、授权混乱，大量物种找不到活体彩色图；也没有一份“一种一图 + 多语种名 + 开放授权”的全球鱼类数据集。

鱼类版和鸟类版有三处本质不同，整份需求都围绕它们设计：

| | 鸟类版 | 鱼类版（实测） |
|---|---|---|
| 物种数 | 11,011 | **38,184**（约 3.5 倍） |
| 没有参考照片的种 | 3.6% | 开放授权照片缺 47%，任何 CC 照片都没有的 37% |
| 名录 | AviList，一个 CC BY 来源覆盖分类、英文名和编号 | 分类用 COL（CC BY），名字靠 Wikidata（CC0），没有统一英文名 |

## 2. 产品目标

| 编号 | 目标 | 衡量指标 |
|---|---|---|
| G1 | 覆盖全世界现生鱼类 | 最终每个接受种都有 1 张贴纸 |
| G2 | 风格统一、能当插画直接用 | v1.0/v2.0 100% 过线；v3.0 没过线的带标记 |
| G3 | 开放授权、可商用 | 贴纸 CC BY 4.0，数据 MIT；发布的数据里没有 NC/ND 授权的内容 |
| G4 | 开箱即用 | 一行 HTML 通过 CDN 加载；用中文名或学名都能查到贴纸 |
| G5 | 诚实透明 | 每张贴纸都标明是 AI 生成、依据了哪一级参考图、体色是否可信 |

**非目标**：不做鉴定工具，不承诺专家级准确度，首期不做网站和 App，不做视频，不画人工品种（金鱼、锦鲤品系等）和亚种。

## 4. 范围与版本

### 4.1 物种范围
- **收录**：Catalogue of Life（2026-11-11 版）中现生鱼类的全部接受种（38,184 种，含盲鳗、七鳃鳗、软骨鱼、辐鳍鱼、肺鱼、腔棘鱼）。
- **不收录**：化石种、亚种、杂交种、人工品种。
- **带灭绝标记的种**（约 300 个）：不主动画；参考资料充足的可以补画，用 `extinctionStatus` 标注。

### 4.2 参考图分级

| 级别 | 定义 | 体色可信度 | 估计占比（全球） | 策略（已定） |
|---|---|---|---|---|
| **A** | 开放授权（CC0/BY/BY-SA）的活体或新鲜个体彩色照片 | 高 | ~50% | 优先使用 |
| **B** | NC/ND 或保留所有权利的活体照片 | 高 | ~10–15% | **使用**，但照片不分发、按授权分类统计、提供 7 天撤图通道 |
| **C** | 只有标本照、X 光片或论文黑白插图 | 低（推测） | ~20–25% | 放 v3.0，标 `colorConfidence: low` |
| **D** | 什么图都没有，只凭文字描述生成 | 低 | ~15% | 放 v3.0，标 `reference: null` |

## 5. 功能需求

优先级：**P0** 当前版本必须有 · **P1** 尽量有 · **P2** 后续版本。

### 5.1 贴纸

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F-01 | 版本范围内每个种都有 1 张贴纸 | P0 | 贴纸数量和数据里的物种数一致 |
| F-02 | 格式：透明底、白色描边、webp、长边约 1000px，平均约 45 KB | P0 | 全量 3.8 万张 ≤ 1.8 GB（实测均值 45.9 KB ≈ 1.67 GB） |
| F-03 | 默认构图：头朝左、正侧面、所有鳍展开、嘴闭合、成年活体体色、浅灰 `#D9D9D9` 纯底生成后再抠图 | P0 | 审核记录里构图项全部合格 |
| F-04 | 特殊体形视角规范（经试画修订）：<br>• 比目鱼（鲽形目）：`eyed-side`（有眼侧朝上，头朝左，注明左/右眼型）<br>• 鳐/魟/电鳐/鮟鱇/蝙蝠鱼/扁鲨等背腹扁平鱼：`dorsal`（背面俯视，吻朝左）<br>• 双髻鲨（Sphyrnidae）：纯 `dorsal` 或纯 `lateral`，**禁止混合扭转视角**<br>• 海马/海龙：`vertical`（竖直，头朝左）<br>• 鳗类/盲鳗/七鳃鳗：`lateral` 全长水平展开，不可截断<br>• 圆盘/高身鱼（翻车鲀、蝴蝶鱼等）：3:2 画布左右留大空白，禁止横向拉长 | P0 | 每张都有 `view` 字段，且与科级规范一致 |
| F-05 | 路径 `stickers/<目>/<科>/<属_种>.webp` | P0 | 和数据里的 `sticker.file` 一致 |
| F-06 | 文件的 XMP 元数据写明：AI 生成（`trainedAlgorithmicMedia`）、AI 系统名、未经专家核对、授权、仓库链接（Pillow 直接写入） | P0 | 脚本校验 100% 含 `trainedAlgorithmicMedia` |
| F-07 | 每张贴纸记录参考图级别（A/B/C/D）和体色可信度（`colorConfidence: high/low`） | P0 | 字段齐全 |
| F-08 | 性二型或体色相变的种，标注画的是雄性、雌性，还是初期相或终期相 | P1 | `dimorphism` 字段 |

### 5.2 质量审核

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F-10 | 每张贴纸由独立的视觉 AI 审核员打分，五项各 0–4 分：辨识、体色斑纹、鳍、头部、体形比例 | P0 | 每张都有审核记录 |
| F-11 | 过线条件：五项都 ≥3、辨识 = 4、`pose_ok = true`、`field_guide_plate_ok = true`、预设结构硬检查全过 | P0 | v1.0/v2.0 100% 过线 |
| F-12 | 结构硬检查（按科预设，**审核员不得自造额外检查项**）：背鳍个数（1/2/3 个）、有没有脂鳍、腹鳍位置（腹位/胸位/喉位/缺）、尾鳍形状、须的对数、鲨鱼鳃裂数、比目鱼眼侧、是否多鳍/少鳍。**不检查鳍条和鳞片数量** | P0 | 审核漏判率 < 10%（试画实测 0%） |
| F-13 | 不过线时，审核员给出 1–3 条可直接放入提示词的修正句，进入下一轮生成 | P0 | 记录可查 |
| F-14 | 每种最多重画 6 次；仍不过线的进入人工队列或局部重画 | P0 | 不会无限重画 |
| F-15 | 发布规则：v1.0/v2.0 100% 过线；v3.0 允许发布最高分版本并标 `meetsQualityBar: false` | P0 | — |

## 6. 非功能需求

| 编号 | 类别 | 要求 |
|---|---|---|

| N-07 | 版权 | 仓库不存任何参考照片；撤图申请 7 天内处理 |
