## 3. 试画发现的 6 个必须改写进需求的坑

1. **不能直接拿 iNat 最高赞照片当参考**：实测虹鳟第 1 赞是水下正面大头照，小丑鱼第 1 赞是海葵里几乎看不见的远景，鲤鱼有鱼缸和人手。**必须增加「10 张候选拼接触表 → 视觉模型自动选 1–3 张清晰侧身图」步骤**。
2. **背腹扁平底栖鱼必须改用 `dorsal` 俯视**：鮟鱇科（Lophiidae）、蝙蝠鱼科（Ogcocephalidae）、扁鲨科（Squatinidae）与鳐/魟一致，画侧面会彻底变形。
3. **双髻鲨（Sphyrnidae）禁止混合视角**：只能用纯 `dorsal` 或纯 `lateral`，绝不写“转 20° 露出锤头”。
4. **高身/圆盘形鱼（翻车鲀、燕鱼、蝴蝶鱼、海马）必须写明留白**：3:2 横画布会让模型不自觉把圆盘鱼拉长成椭圆，提示词里要明确“左右留大片空白，不要拉长身体”。
5. **审核员不得自造额外检查项**：`Silurus_asotus` 和 `Siniperca_chuatsi` 两张已经 `id=4, plate=True`，只因审核员在 `structural_checks` 里自己多加了主观细项被判不过线。审核规则改为：**`structural_checks` 严格限定为特征卡预设的清单，禁止新增项**。
6. **抠图必须用神经网络抠图（`BiRefNet` / `rembg`），不能用纯色泛洪填充**：实测纯色泛洪填充对深色鱼（狮子鱼）完美，但会啃掉浅色/半透明鱼鳍（如丝蝴蝶鱼的白色腹鳍）。

## 4. 成本与运行方式定论

- **配额教训**：交互式订阅配额每 ~5 小时仅支持约 45–50 次生图，无法跑 3,500+ 物种。**正式生产必须使用付费 Batch API（Gemini Batch API 或 OpenAI Batch API）**。
- **费用精算**（按实测平均 **2.0–2.3 轮/种**，Batch API 享 5 折）：

| 版本 | 物种数 | 预计生图次数 | Batch API 估算（生图+审核+选图） | Standard API 估算 |
|---|---:|---:|---:|---:|
| **v1.0 首发**（中国 A/B 级 + 常见观赏/经济鱼） | ~3,500 | ~7,700 | **\$150 – \$250** | \$300 – \$500 |
| **v2.0 全球 A/B 级** | ~23,000 | ~50,000 | **\$1,000 – \$1,600** | \$2,000 – \$3,200 |
| **v3.0 全球 C/D 级** | ~15,000 | ~35,000 | **\$700 – \$1,200** | \$1,400 – \$2,400 |

- **C/D 级剩余说明**：本次仅因配额中止未能跑完 2 种标本照（C 级）和 2 种冷门无图种（D 级）；v1.0 与 v2.0 均不含 C/D 级，故不影响进入执行。v3.0 启动前再补跑 10 种 C/D 级试点即可。
